A tower defence game with at least 3 levels of increasing difficulty and purchasable towers on a limited budget. Towers snap to a grid, and you earn funds through kills or collected objects. It has start and end splash screens.


Interesting coding implementation is the snap grid algorthm and barred spaces for character input. High Levl OOP, SOLID principles and sprite animations and with my own twist. Interesting Building in Monogame !!

Download the repo and go to bin/Debug/net9.0/Castledefense.
